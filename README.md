# 续作 · REVIVE 0.2.40

找回电脑里散落的创作项目，接着做下去。Windows x64 桌面版，基于现有 OPSU 数字空间的 Electron / React 底座与玻璃视觉，项目浏览方式参考用户提供的视频。

## 打开软件

- 免安装：运行 `release/win-unpacked/续作.exe`。保留整个 `win-unpacked` 文件夹。
- 安装版：运行 `release/OPSU-Revive-x64-Setup.exe`，可选择安装位置。默认不新增桌面快捷方式。
- 首次使用可点击“扫描我的项目”，或拖入项目文件夹。此电脑默认扫描位置为 `E:/Codex`，可在设置中更改。

## 打包与更新

- `npm run package` 始终更新固定的 `release` 目录，安装包名称保持不变，不再按版本复制完整程序。
- 打包前会正常关闭该目录中运行的续作；成功后恢复原先打开的程序。
- 可用 `npm run package -- -ElectronDist <Electron 运行时目录>` 复用本机运行时。

## 使用边界

- 这是本地项目管理器。第一版未提供第三方 AI 工具的完整对话自动恢复，也不会自动执行 AI 开发任务。
- 扫描默认向下查找 6 层，发现项目后不再进入其内部识别子项目。可把单个子项目文件夹独立添加为扫描位置。
- 自动跳过依赖、缓存、构建、work、历史归档及工具链目录。单次最多检查 25,000 个目录、发现 3,000 个项目；触及上限会在底部提示。
- 最近修改时间来自入口文件及常用源码目录的限量快速扫描。源码大小不含依赖和构建产物，超过 30,000 个文件时显示“至少”。
- Git 改动数量仅统计已跟踪文件，未跟踪文件不在此数字内。
- 会话匹配读取本机可找到的 Codex / Claude Code JSONL，不调用在线模型；其他开发工具目前主要按项目配置标记识别。部分历史会话、格式差异或路径变更可能无法匹配。
- 开发预览需要已安装 Node.js 和项目依赖。启动预览会执行卡片所示的原项目 npm 脚本；关闭预览窗口会停止此次启动的开发服务。源项目本身的脚本可能有自己的写文件等行为。
- “继续开发”前可在设置中选择 VS Code / Cursor 等编辑器 EXE；未设置编辑器时仍可复制上下文。
- 扫描只建立索引，隐藏项目及移除扫描位置不会删除或移动原项目。应用数据保存在 Windows 当前用户的应用数据目录 `续作/library.sqlite`；项目内容仍在原位置。
- 目前支持导出索引，尚未提供导入与云同步。

## 源码开发

依赖锁定在 `package-lock.json`。使用 Node.js 24 与 npm：

```text
npm install
npm run build
npm start
npm test
npm run package
```

若本机 npm 配置禁用了安装脚本，需要另外运行 `node node_modules/electron/install.js` 安装 Electron 运行时。生产安装包不需要用户安装 Node.js；只有开发预览原项目时需要。

核心代码在 `electron/`，界面在 `src/`。SQLite 使用 Node.js 内置 `node:sqlite`。窗口启用 contextIsolation 与 sandbox，渲染层无 Node 权限；项目网页预览没有应用的 IPC 桥接，服务只监听 127.0.0.1。

源码保留数字空间中的 atom63/halftone-animation 背景适配实现作为历史资源，本版项目库未启用它。MIT 许可随包放在 `public/licenses/halftone-animation.txt`。品牌图标为本项目独立矢量资产，源文件 `build/icon.svg`，选色记录与透明通道检查见 `build/brand.json`。
